# 桶桶队长：宝藏大发现

入口 `/play/bucket-captain`。照片定制的四岁儿童拖拽拼装游戏。

## 当前玩法

四十九个作品：保留原有十九种成品，新增三十种难易兼有、贴近日常的认知主题。气泡中展示彩色成品，场地显示虚线外轮廓，轻松模式额外显示分块线，4至8个零件及最多2个干扰零件同时放在草地上，可按任意顺序拖入对应位置。轻松模式接近时目标高亮，松手吸附并发出短促咔哒声；放错回到原位，没有扣分和时间限制。单击零件只提示如何拖动，不再执行选择题式的自动组装。

组件美术直接由各自成品的生成图导出，并按与成品对齐的不规则多边形精确切分：每块与成品完全注册，避免独立绘制的配件比例、角度不吻合。`assets/puzzle-*.png` 为384×384或512×512，CSS裁切而非实时像素处理。完成后仍保留原作品的起飞、跳舞、玩耍互动，以及斑马完成时播放用户原声。

## 触摸与兼容

- 优先 Pointer Events 和 pointer capture；无 PointerEvent 时回退到 touchstart/touchmove/touchend 和鼠标事件。
- 不使用 HTML 原生 drag-and-drop；仅在拖拽过程中阻止触摸滚动。
- 自动吸附半径为成品宽度16%，单图至少42px、双图至少32px；拖动中以实际屏幕坐标计算目标，转屏和暂停会安全取消当前拖动。
- 键盘用户可聚焦按钮后按 Enter 或空格听提示，拼装需要拖动。
- 暂停冻结动画、音频和定时器，继续恢复；本机完成记录保留。
- 面向 iPad 2018 的1024×768与768×1024布局；无 WebGL 或永久逐帧渲染循环。只有拖动事件更新零件位置。
- 已在 Chromium 和 WebKit 触摸配置下验证；未声称完成 iPad 2018 实机验证。

## 美术与音频

主角三姿态、庭院、作品、菜单按钮均源自本项目的 ImageGen 素材。照片原图不在发布目录。菜单为继续、声音、重新探险三个圆形软陶图标。

当前背景音乐为原创《桶桶队长的花园》初稿，`assets/bucket-garden-loop-v1.wav`，104 BPM、16小节、约36.923秒，立体声44100Hz，可循环。木琴、拨弦、轻打击乐配器，由 `scripts/build-bucket-music.py` 制作；原 Toy Town Adventure 音频仍保留，便于比较。斑马原声 `wo_shi_ban_ma_clean.wav` 原样复制为 `assets/zebra-voice.wav`，0.82秒，合成后自动播放，点击斑马可重听；暂停、静音和换任务会同步处理。首次交互静音解锁媒体播放器以兼顾旧版 iPad 限制。

## 验证

`cargo run -- --check` 校验游戏目录。`node scripts/check-bucket-captain.cjs` 执行 Chromium 回归；设置 `BUCKET_BROWSER=webkit` 切换 WebKit。支持 `PLAYWRIGHT_MODULE`、`MONSTER_BROWSER_PATH` 指定本地依赖和 Chromium。

覆盖十九任务、真实鼠标拖动、错位不吸附、任意顺序、点击不能完成、暂停取消、横竖屏和手机布局、旧版 touch 回退、斑马完成语音。截图位于 `target/bucket-captain-check/`。

## 虚线轮廓与下一站

轮廓 SVG 从每张成品的透明形状提取，内部不填色、不使用半透明成品。纯外轮廓 SVG 不带分块线；轻松模式另外按当前切分绘制分块虚线。填入的零件与轮廓对齐；求助时只高亮对应的轮廓。完整彩色参考图固定显示在对话气泡内。

新增的五种成品和圆形“下一站”箭头均单独由 ImageGen 生成，保留完整形状、正常比例；不再裁切木牌。九个完成标记可折行，旧本机完成记录自动扩展并保留。
## 随机顺序

开场和重新探险均随机选择第一站。“下一站”从洗牌后的十九个作品队列中取出：一轮内不重复，全部玩过后重新洗牌，并避免两轮交界连续出现同一作品。

每局使用 Fisher–Yates 打乱本局全部零件的摆放顺序，连续两局不复用同一排列。位置、吸附和已放置状态始终按零件编号识别，不依赖左右顺序。

## 十种长隆动物与变化切分

动物参考长隆官方展区介绍：https://www.chimelong.com/gz/safaripark/exhibition/ 。新增大熊猫、白虎、非洲狮、亚洲象、白犀牛、河马、大赤袋鼠、鸵鸟、川金丝猴、黑猩猩，均单独用 ImageGen 生成512像素完整透明成品。

全部作品现统一使用按可见图案分布生成的 4、5、6、8 块不规则多方向切分，运行时布局位于 `puzzle-cuts.js`。`puzzle-layouts.json` 与旧轮廓保留为旧版制作资料。

白边应用于裁切后的图层，包括零件外沿和拼缝，避免只描成品外轮廓而漏掉切边。拖动与静态填入都共享同一组多边形，虚线 SVG 也依据同一布局导出。`python scripts/build-bucket-outlines.py --force` 可重建轮廓（仅制作工具依赖 Pillow/NumPy/SciPy/scikit-image，浏览器没有这些依赖）。

十九站时进度显示为星星加完成数量，避免小屏堆积十九个图标；旧进度按既有作品下标自动保留。

## 吸附声音与动效设计

吸附改用三档预制分层音效 `snap-seat-1/2/3.wav`（0.32秒），包含材质接触、48ms后锁扣、短泛音，随完成进度逐步升高；最后一块追加0.39秒的完成音阶 `snap-complete.wav`。作者工具 `scripts/build-bucket-snap-audio.py` 可确定性重建素材。峰值0.87，输出经过温和动态压缩，避免快速连续操作过载。

吸附时配乐短暂降至3.8%，与语音音量协调恢复。Web Audio 存在时预解码为 AudioBuffer，首次拖动后即可低延迟触发；缺少该接口时自动使用已解锁的原生 Audio 后备（WebKit Windows 实测）。静音和暂停立即停止包括延迟完成音在内的短音源，恢复后不重放旧点击。

视觉对应压合回弹、接缝暖亮、扩散圆环和四颗短星屑，最后完成的成品轻弹。减少动态效果时关闭这些运动。设置 `BUCKET_SNAP_ONLY=1` 可执行专项回归，覆盖四段音频解码、错误放置不奖励、配乐压低、动效同步、最后一块、暂停停止音源、静音和减少动态效果。


### 拼图难度

暂停菜单可选七档难度，默认动脑，原有三档为轻松、动脑、挑战，设置自动保存。轻松为 4 块并显示裁切分线；动脑连续独立顺利完成后，从 4 块升到 5 块、6 块，并混入 1 块其他作品的零件；挑战为 8 块加 2 块干扰零件。无倒计时或扣分，放错三次提示位置，点小队长或气泡也可求助。切换难度重开当前成品。

所有 19 幅成品使用按透明度图案分布生成的不规则多方向切分，零件随机排列，可任意顺序拼装。草地零件区最多两排，保留至少 44 像素触摸范围、白边和宽松吸附。`scripts/build-bucket-cuts.py` 可重新生成 `puzzle-cuts.js` 与纯轮廓 SVG；仅制作时需要 Pillow 和 NumPy，浏览器无需新增依赖。


### 空间高手与混拼大师

暂停菜单新增两档机制难度，沿用每幅 8 块的切分。空间高手点按零件旋转 90°、按住拖动，只有位置和方向都正确才吸附；刚进入时随机转动 2 块，独立顺利完成后逐渐增加到 8 块。混拼大师同时完成两幅不同作品，共 16 块，点按旋转的规则相同。共用草地上始终最多展示 8 块，拼入后从预先随机打乱的剩余零件中补入，不按作品或上下位置分批。两幅都完成才显示下一站，点击任一成品触发双人庆祝。

混拼先搭配辨识度不同的作品，熟悉后优先搭配相近动物，如斑马与白虎、狗熊与熊猫，并逐渐增加需要旋转的零件数。两档熟练进度独立保存，切换难度不清除。提示只指出零件与位置，不自动转正；拖动失败、暂停、手势取消均不会改变角度。旧版无 PointerEvent 的 Safari 使用相同的触摸点按／拖动判定。

`BUCKET_MECHANICS_ONLY=1` 执行新机制专项检查：错方向与错作品拒绝吸附、一次点按只转 90°、递进旋转、随机零件补入、双图完成和共同动画、五档设置保存、横竖屏与小屏布局、旧版触摸回退。

新模式仍保留宽松吸附与白边。旋转以真实点按触发，每次只转 90°；手指移动超过 8 像素才进入可见拖动，避免点按时拼块突然跳大。新布局在支持 CSS min/max 的 Safari 上直接随视口调整，并为旧浏览器保留原尺寸计算回退。


### 记忆大师与空间变换大师

记忆大师沿用双图各 8 块、混合补入与点按旋转。先在两个拼装垫上展示完整作品，观察时间由孩子决定，点「记住啦」后才开始拼装。正式拼装时收起成品参考及全部外轮廓，只留空白拼装垫；点小队长、气泡或连续放错三次可再看 3.5 秒，不扣分。再看期间只展示参考，不标出单块位置；暂停会冻结再看计时，切换场景或完成会清理计时，避免旧提示覆盖新状态。

空间变换大师保持气泡里的参考图正立，目标轮廓与整个作品的拼装方向一起改变。入门每轮随机让一边转向 90° 或 270°，熟练后让两边分别朝两个不同的方向（可含 180°）。一轮开始后方向固定，暂停、调整窗口或屏幕旋转都不改变目标。吸附中心随整图变换，拼块当前角度必须与目标方向匹配；拖动锚点仍位于零件可见中心。填入图层、接缝反馈和完成后的成品均保留目标朝向，庆祝动画不覆盖这层旋转。

两档熟练进度独立保存，沿用每次最多 8 块的大触摸目标。`BUCKET_ADVANCED_ONLY=1` 专项检查覆盖自主观察、隐藏参考与轮廓、反复再看及暂停计时、记忆模式完整通关、90°/180°/270° 的目标坐标与角度、错误方向和旧坐标拒绝吸附、七档菜单、三种屏幕尺寸及进度保存。


### 三十种认知主题

保留原有 19 个下标并追加 30 项，因此旧完成记录无需迁移。新增题材为：

- 果蔬与食物：苹果、香蕉、草莓、西瓜、菠萝。
- 生活用品：书包、雨伞、闹钟、牙刷、运动鞋。
- 工程与救援：挖掘机、推土机、压路机、混凝土搅拌车、云梯消防车、救护车。
- 交通工具：高铁、直升机、热气球、帆船、自行车。
- 社区与科学：红绿灯、灭火器、显微镜、望远镜、风力发电机。
- 身边自然：蜜蜂、蜗牛、向日葵、乌龟。

新图均为内置图像生成工具制作的软陶透明美术，导入为 512×512 PNG，生成 4/5/6/8 块切分及虚线轮廓。清单与部件、用途介绍见 `discovery-items.json`，运行时对应 `discovery-items.js`。七档难度共用所有 49 种成品，双图熟练后优先搭配同类题材，例如工程车之间、果物之间。完成新作品会用系统中文语音介绍，点击成品可重听；双图中分别点击两个作品会讲各自的内容，斑马用户原声保留。屏幕只显示简短反馈，不铺满介绍文字。

`scripts/build-bucket-discoveries.py` 负责导入、透明度检查、统一尺寸、记录提示词及生成审阅图；`artwork/discovery-prompts.json` 保存最终美术提示词与来源校验值。原始生成图留在生成目录，导入后项目只引用自身的资源。更新流程依次运行该脚本、`build-bucket-outlines.py`、`build-bucket-cuts.py`。

`BUCKET_DISCOVERY_ONLY=1` 检查 49 站无重复通关、新增 30 种成品及各块数布局、旧进度下标保留、完成自动介绍和重听、同类双图搭配及两个作品的介绍分别对应。
