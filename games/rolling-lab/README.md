# 奇妙实验岛：滚球山坡

入口 `/play/rolling-lab`。首个完整实验场景，面向3至4岁起的观察、预测、单一变量控制和比较练习。无倒计时或扣分，进入即玩，暂停菜单里选择24个任务、惊喜探险或自由探索；旧版六关的进度自动保留。

## 玩法

直接拖坡道或点圆把手，在低、中、高三种释放高度间切换；点场景里的跑道循环木板、毛毡、草地，点小球本身发射。小球触控区域至少64像素。默认不要求预测，家长可在暂停菜单开启“预测挑战”，之后可在跑道上方放旗，第二关起放旗后发射。

前六关依次为：碰响近处铃铛、送到更远铃铛、固定高度换表面、比较两个高度、比较两种表面、停进接球篮。最后一关有多种可行组合，不能靠始终调到最高或最光滑过关。后两种比较任务必须留下两个条件不同的实验结果。

新增三组各六关：积木乐园要求撞倒沿路积木后停进篮子；风车山谷可以切换逆风、关闭、顺风；机关实验室组合风、积木与固定草地刹车毯。所有新关卡的目标均从模型的可行结果选取，初始条件不会直接完成目标。每关可以收集三个独立徽章：完成、预测接近（误差小于65场景单位）、做过条件不同的对照实验。徽章可分次收集，鼓励观察和重玩，不以速度或少尝试次数计分。

第24关后进入惊喜探险；家长菜单也可直接进入。挑战按保存的种子生成，不会紧邻重复相同机关与目标，每道均枚举验证可解。探索次数和当前题目保存，刷新仍为同一题。自由探索里可以组合切换积木、刹车毯与三档风向。

最近四次轨迹保留在内存里，主画面不展示旧脚印、旧旗子或徽章；需要比较时在暂停菜单选择回放。回放同时播放最近两条轨迹，沿用各自真实实验时长，不改变记录或判定。高度不同时显示上次坡道的半透明轮廓，两次表面用材质小图展示。每次实验后只允许改变高度、表面或风向中的一项，可在暂停菜单撤回到上次条件。未成功时小球短暂停留，让孩子看清结果后回到起点，可以继续调整机关再发射；成功时小球留在目的地，收起调整操作，仅突出下一关。家长可在暂停菜单选择“继续研究这关”，保留本关实验记录并恢复操作。

## 模型及兼容

`physics.js` 为确定性、固定1/120秒步长的简化实心球纯滚动模型。坡道沿斜面重力加速度取5/7系数，并使用固定小滚动损耗；水平段采用三档有效滚动阻力，数值用于游戏内比较，并非真实材料的实验测量值。理想化处理坡道与水平面的平滑衔接，不模拟质量、空气阻力或弹性碰撞，所有实验使用相同球与相同空间尺度。跑道尽头有可见软垫，触及时会停止并明确提示，不把碰撞截断误说成自然停止距离。

只有运动、回放或短暂庆祝时使用RAF。所有设备共用预计算轨迹，显示帧率不会影响结果；暂停停止声音与动画，恢复重置显示计时基准，离开页面自动暂停。Canvas DPR上限为2，无WebGL，原生Pointer Events并提供旧Safari触摸回退。记录24关的完成状态、独立徽章及探险进度，本地键为 `rolling-lab-v1`。

风作用于跑道470至940的区间，采用固定水平加速度；逆风不会把已经停下的球反向吹走。撞倒一块积木会消耗固定动能，不足时小球停在积木前；每块积木随记录的碰撞时刻倒下并发声。刹车毯区间覆盖普通跑道的阻力。参数是供幼儿观察对比的简化游戏模型，不模拟真实风场、完整刚体碰撞或积木间的连锁碰撞。

## 美术与声音

全部美术由内置图像生成工具制作，采用水粉和彩铅绘本风；庭院、角色及庆祝姿势、坡道、球、铃铛、篮子、小旗、脚印、材质、操作按钮与引导手势均为生成图片。素材在 `assets/`，生成提示词见 `artwork.json`。Canvas负责图片布局、旋转和运动，仅功能性的比较连接线使用几何绘制。主界面由实际场景表达目标：小熊在目的地篮子旁等球，或小球碰铃铛。主画面移除顶部公式图示和底部工具栏，进度与回放可以在暂停菜单查看。连续10秒没有操作时，当前可操作区域轻闪两下。触摸、拖动或按键会清除提示，暂停和滚动中不显示。所有装饰与机关沿用已生成的美术。完整文字只供屏幕阅读器或家长菜单使用。滚球和碰撞采用实物录音。滚动声随球速改变音量和速度，根据木坡、路面和刹车毯交叉淡化。木块、铃铛、接球篮和软垫分别在实际接触时发声。语音提示由家长从暂停菜单主动播放。首次操作解锁音效。暂停和静音会停止音效。录音来源及处理见 [音效说明](assets/foley/SOURCES.md)。

## 检查

`scripts/check-rolling-lab.cjs` 先检查同表面增高距离单调、同高度增加阻力距离单调、所有轨迹有限且时长合理，再通过浏览器完成六关、预测前置、暂停冻结、单变量规则、撤回、无副作用回放、自由模式、进度恢复和旧版触摸。覆盖1024×768、768×1024及390×844。`ROLLING_BROWSER=webkit` 选择Safari内核；没有声称进行实体iPad测试。

深度检查 `scripts/check-rolling-depth.cjs` 验证24关及1000个随机题均可解、初始状态不能直接完成新关，检查风向、撞击损耗与刹车阻力，并通过实际界面完成全部18个新关和连续随机挑战；覆盖徽章、恢复原题、自由机关组合、iPad/手机风扇触控区域。
