# 画出来的路

游戏入口为 `/play/draw-road`。玩家先在画布上画，再点小球开始实验。开放笔画会变成有厚度的刚体，闭合图形会变成实心零件。画线经过有转轴的关卡中的金色轴心，就会连接到轴上。按撤销可删去最后一笔，实验失败会保留画稿。

50 关分成十组，依次引入支撑、斜面、挡板、配重、摩擦、转轴、连锁机关、双球和笔数限制。后半段包含受力转轴、能压住或碰响的触发器、依次释放的球和按颜色判定的篮子。每关的示例画法存于 `levels.js`，只供验证；玩家画出的碰撞体决定实际结果。

部分关卡用蓝纸标出独立的搭建台，笔迹能画到纸边。实心纸箱既挡住小球，也不能用笔迹穿过。桥和开关能在不同台面分工，带有两把锁的门会等两个实际触发信号。需要初始速度的小球有纸板弹簧发射器，推杆和弹响随模拟中真正释放的时刻触发。

主场景没有文字教程或持续手势。闲置 10 秒时，画布、放球或下一关的可操作区域会短暂提示。关卡说明和自由选关在暂停菜单里。本机保存当前关卡、画稿、完成进度和声音设置。

三张背景、封面及纸板道具由图像生成工具制作，生成记录见 `artwork.json`。球的其他颜色由同一图像变色得到。动态笔画、操作标记与反馈由程序绘制。

物理由本地的 Matter.js 0.20.0 处理，许可证随库放在 `vendor/`。固定 120 Hz 模拟步长，Canvas 像素数有上限，无需 WebGL、外部 CDN 或安装账号。触控使用 Pointer Events，并提供传统 Touch Events 路径。失败时可立即重试，也会在短暂停留后自动回到可编辑画稿。停滞的模拟会结束，画图时没有计时限制。

`node scripts/check-draw-road.cjs --physics-only` 检验 50 关参考解、空画布结果、图形质量、机械顺序和通用斜坡绕法，也逐一移除设计为多步骤的关卡里的参考动作。不带参数会额外通过本地游戏入口绘制代表性关卡。可用 `DRAW_BROWSER=webkit` 或 `DRAW_GAME_URL` 指定浏览器和地址。
