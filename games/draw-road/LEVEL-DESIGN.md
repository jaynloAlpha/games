# 50 关设计与递进

入门每关只突出一个动作，孩子可以先放球观察。第 6–15 关转向、分段接球和预判反弹。第 16–35 关逐步引入压住、配重、摩擦、转轴和传力。第 36–45 关需要分工或让同一笔兼做两件事，第 46–50 关再把学过的机关串起来。发射时所有球立即运动，球遇到实体门会停下、撞开或弹走。

| 关卡 | 玩家要发现的事 |
| --- | --- |
| 01 | 连接小沟的两端，让球有路可走。 |
| 02 | 高处落下的球可以沿倾斜的画线拐弯。 |
| 03 | 路已经通了，画一块能站稳的挡板让球停下来。 |
| 04 | 中间桥墩太窄，两段桥要分别放对地方。 |
| 05 | 让画出的凹槽接住斜着飞来的球。 |
| 06 | 让球沿单边斜面向左转。 |
| 07 | 红球要碰过路上的铃，再进同一个篮。 |
| 08 | 高路被箱子封住，用下面的通道接球。 |
| 09 | 先向右接，再反方向往左送。 |
| 10 | 一段路负责接球，另一段路把球送过更低的缺口。 |
| 11 | 先看一次弹跳，再在落点接住小球。 |
| 12 | 球会撞上竖着的弹垫，画一段向左下方走的路接住回弹。 |
| 13 | 让小球够到空中的铃，并给下落留好去处。 |
| 14 | 用弹跳越过纸箱，接住落到箱子左侧的球。 |
| 15 | 先把球送到弹垫，再接住弹出来的球。 |
| 16 | 用一块会掉下来的积木压开关。 |
| 17 | 落物还要留在开关上，门才保持打开。 |
| 18 | 用一块较大的积木或叠放两个小零件，让托盘承受足够重量。 |
| 19 | 用能滚动的形状推一扇会荡回来的门。 |
| 20 | 分别安排两个配重，两把锁都打开才能过去。 |
| 21 | 用桥把球引上光滑的长桌面，借余速走远。 |
| 22 | 让毛毡慢慢吃掉速度，再用挡板停在圈里。 |
| 23 | 让滚动件穿过光滑路，把重量送到远处的开关。 |
| 24 | 在两块防滑支座上放稳斜板，避免滑落。 |
| 25 | 先从缺口过去，再用毛毡把球收在指定范围里。 |
| 26 | 画一笔穿过金色轴心，长一点的一端会自己往下转。 |
| 27 | 用配重让本来较轻的一端压下去。 |
| 28 | 让同一根转动的杆依次碰到两把锁。 |
| 29 | 画一根翻板去开门，再在另一张纸上搭过沟的桥。 |
| 30 | 给另一边做配重，让两块零件在反方向合作。 |
| 31 | 用画出的滚动件碰倒一块积木，积木才会触发门。 |
| 32 | 第一个积木只负责传力，由第二个打开门。 |
| 33 | 让球先落到低处托盘上，再用配重抬升托盘。 |
| 34 | 用会滚动的零件触发小车，把球运过空处。 |
| 35 | 用杠杆启动托盘，在另一处补接球的路。 |
| 36 | 画两条互不干扰的路，把红蓝球送进同色篮子。 |
| 37 | 一条倒 V 形的棱把两个来球分别送向两边。 |
| 38 | 红球只负责碰铃，蓝球必须安稳进篮。 |
| 39 | 红球从低处经过开关，给先到门前的蓝球开路。 |
| 40 | 一块分流板既让红球碰铃，也让蓝球落到门前的短坡。 |
| 41 | 一笔搭出的桥还要碰到它末端的小开关。 |
| 42 | 两笔分别盖好仓库下方的路和高处的锁。 |
| 43 | 一笔画出横跨两枚相邻开关的零件。 |
| 44 | 一笔做转轴杆，让往相反方向转的两端各拨动一把锁。 |
| 45 | 一笔分开两颗球，分别落到比练习关小的接球篮。 |
| 46 | 弹跳越障后还有空档，画出两段互相接得上的路线。 |
| 47 | 让转轴打开前面的门，再用两座桥把球送过缺口。 |
| 48 | 红球沿自己的路去按开关，叫来载蓝球的小车。在对岸另外补一段接车的坡。 |
| 49 | 红球撞铃，重物按下另一把锁，蓝球才能穿过门。 |
| 50 | 先安排两颗球入篮，最后一颗球从活动托板落下敲响庆祝铃。 |

验收时逐关跑参考画法与空画布，并对需要配合的关卡去掉其中一项试跑。关键物理现象用去掉弹性、固定托盘或拿掉压住开关的物体来复核。允许替代路线，避免要求玩家照着答案描。
